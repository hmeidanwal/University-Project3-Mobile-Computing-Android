# Guidelines

## Meetings
- Retrospective: Monday, 15 minutes.
- Stand-up: 5 minutes daily on days there is no retrospective.
- Sprint planning: Monday, 60-120 minutes, immediately after the retrospective.
- Create a short summary after each meeting and attach it to the spint summary file.

## Project board / Tickets
- During sprint planning agree on the functionality and create tickets for each item.
- Place new tickets in "To Do".
- Immediately assign the ticket to yourself when you start working on it.
- Ensure each ticket has a clear, up-to-date description.
- Update your tickets daily with progress or notes.
- Before the retrospective, move unfinished work back to "To Do".
- When someone reviews or merges a pull request, update and move the corresponding ticket accordingly.
