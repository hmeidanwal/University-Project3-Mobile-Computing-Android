# University Project 3 - Mobile Computing Android

This project is a **mobile price comparison application** developed as a group project at **Fontys University of Applied Sciences**.
The application allows users to compare products and prices from different supermarkets. Users are required to create an account before using the application.
The original vision was to retrieve live product and pricing data directly from supermarket APIs. However, access to these APIs is generally restricted, so alternative data was used for demonstration purposes.

## Key Features

- User registration and authentication
- Taking a profile picture using the device camera
- Comparing supermarket products and prices
- Finding nearby supermarkets using a map and location services
- Receiving push notifications for discounts and newly added products
- Communication with a backend service through a REST API

## Key Technologies Used

- Android Studio
- Kotlin
- LoopBack
